Local evidence tools

Check an evidence bundle

Match the original files against the SHA-256 commitments in a Model Claim Replay run manifest. The selected bytes stay in this browser tab. No uploads, storage, or model calls.

Select original files

Supports portable-text v1 and Inspect v1 run manifests. Maximum 16 MiB per file. Choose the original bytes, not reformatted copies.

Check results

Select a bundle to check its commitments.

What this check establishes

Matching digests establish consistency with the supplied manifest only. The manifest itself is untrusted. This tool does not validate the full schema, authenticate a provider, recompute scores, or reproduce a benchmark claim.

Use the CLI for the complete bundle validation and scoring procedure.

Try a real file-integrity check

Generate the packaged synthetic bundle locally. Then select its four files above. Modify one byte of a copy of the results file and check again to see the mismatch.

python -m pip install "git+https://github.com/fraware/model-claim-replay.git"
claim-replay demo
claim-replay verify .runs/demo/run --claim .runs/demo/claim.json --tasks .runs/demo/tasks.jsonl

The fixture produces 2/3 exact matches; it contains no real model responses. For Inspect bundles, use the Inspect import and validation guide.
